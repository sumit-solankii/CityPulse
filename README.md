# 🌆 CityPulse

### Smart Civic Data Dashboard for Connected Neighborhoods

CityPulse is a web-based civic dashboard designed to bring important city and neighborhood information together in one place.

The platform collects and displays data related to **weather, air quality, traffic activity, and civic incidents** through an interactive dashboard and map.

The main goal of CityPulse is to make civic information easier to understand through **data visualization, maps, charts, and a centralized dashboard**.

---

## 🚀 Features

- 📊 Interactive civic data dashboard
- 🗺️ Interactive map for displaying civic data
- 🌦️ Weather information
- 🌧️ Rainfall observations
- 🚗 Traffic activity monitoring
- 🚨 Civic incident monitoring
- 🌫️ Air quality and PM2.5 information
- 📈 Civic data trend charts
- ⏱️ Last 1 hour, 6 hours and 24 hours data views
- 🔄 Data refresh and source health monitoring
- 📍 Location-based civic information
- 📱 Responsive dashboard interface
